# كريم السيد | KARIM ELSAYED — متجر ملابس ستريت وير (واجهة ثابتة)

متجر عربي RTL بـ HTML + CSS + JavaScript خالص، بدون خادم أو قاعدة بيانات أو خدمات مدفوعة، ويعمل على GitHub Pages.

> **تنبيه:** المنتجات الظاهرة **نماذج تجريبية** وليست مخزونًا حقيقيًا. الأسعار والأسماء والصور قابلة للتعديل بالكامل.

## هيكل المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة (المتجر، المصمم، السلة، الطلب، لوحة الإدارة) |
| `styles.css` | التصميم (أسود/أبيض/رمادي، جوال أولًا، يدعم عرض 320px) |
| `app.js` | كل المنطق: المنتجات، البحث، السلة، المصمم، واتساب، الإدارة |
| `products.js` | الإعدادات (`STORE_CONFIG`) والمنتجات التجريبية |
| `README.md` | هذا الشرح |

## التشغيل محليًا

1. ضع الملفات الخمسة في مجلد واحد.
2. افتح `index.html` بالنقر المزدوج في المتصفح.
3. (اختياري) خادم محلي: `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## ضبط رقم واتساب

افتح `products.js` وعدّل:

```js
WHATSAPP_NUMBER: "201001234567"
```

رقم دولي بدون `+` أو مسافات (مصر: `20` ثم الرقم بدون الصفر الأول). ما دام الرقم `YOUR_WHATSAPP_NUMBER` فلن يفتح زر الطلب واتساب، وستظهر رسالة تنبيه.

## تغيير الأسعار

- **من الكود:** عدّل `price` و`discountPrice` لكل منتج في `products.js`. كل الأسعار في الواجهة تُقرأ من بيانات المنتج.
- **سعر التيشيرت المخصص:** `CUSTOM_TEE_PRICE` في `products.js`.
- **رسوم التوصيل:** `DELIVERY_FEE` و`FREE_DELIVERY_FROM` في `products.js`، أو من «إعدادات المتجر» في لوحة الإدارة.

## إدارة المنتجات (لوحة محلية تجريبية)

افتح `index.html#admin` أو اضغط «لوحة الإدارة (تجريبية)» في الفوتر. يمكنك إضافة وتعديل وحذف المنتجات، رفع الصور (حتى ٤ لكل منتج)، ضبط الأسعار والخصومات والمقاسات والألوان والأقسام والمخزون، تفعيل الطباعة حسب الطلب، ونشر/إخفاء المنتج، واستعادة المنتجات التجريبية. تظهر رسائل تأكيد بعد كل إجراء، ويُطلب تأكيد قبل الحذف والاستعادة.

صيغة الألوان: سطر لكل لون، مثل `أسود:#111111`.

## مصمم التيشيرت المخصص

1. اضغط «اختيار صورة» (JPG / JPEG / PNG / WEBP، حتى ٥ ميجا). تُصغَّر الصورة تلقائيًا لتوفير مساحة التخزين.
2. اختر لون التيشيرت والمقاس والكمية والوجه (أمامي/خلفي).
3. اسحب الصورة لتحريكها، واسحب الدائرة في ركنها أو استخدم الشريط لتغيير الحجم. تبقى الصورة داخل منطقة الطباعة. يعمل على اللمس والماوس، ولا يتعطل تمرير الصفحة خارج الصورة.
4. «استبدال الصورة» و«إزالة الصورة» و«إعادة ضبط التصميم» متاحة. اضغط «أضف التصميم إلى السلة».
5. لتصميم تيشيرت آخر بصورة مختلفة، استبدل الصورة وأضفه مجددًا؛ كل تصميم عنصر مستقل في السلة.

المعاينة **ثنائية الأبعاد توضيحية** وليست مجسمًا ثلاثي الأبعاد، وقد تختلف نتيجة الطباعة النهائية قليلًا.

## الطلب عبر واتساب

يُكوّن الموقع رسالة عربية فيها بيانات العميل والمنتجات والمقاسات والألوان والكميات وتفاصيل الطباعة والأسعار والمجموع والتوصيل والإجمالي، ثم يفتح رابط `wa.me`. فتح واتساب **لا يعني أن الطلب أُرسل**؛ على العميل الضغط على «إرسال» داخل واتساب. **لا يوجد أي دفع** عبر الموقع.

رابط واتساب **لا يستطيع إرفاق صورة من جهاز العميل**، لذلك يُطلب من العميل إرفاق صورة كل تصميم مخصص يدويًا، وتذكر الرسالة اسم الملف وموضع الصورة وحجمها. عند وجود عدة تصاميم تُرفق صورة لكل تصميم. إن كان نص الطلب طويلًا جدًا فاستخدم زر «نسخ نص الطلب» ثم الصقه في المحادثة.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع الملفات الخمسة إلى الجذر.
2. من **Settings → Pages** اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم **Save**.
3. بعد دقائق يصبح الموقع على `https://USERNAME.github.io/REPO/`.

كل المسارات نسبية فتعمل داخل مجلد فرعي. الخط (Cairo) يُحمَّل من Google Fonts مجانًا، وإن تعذر تحميله يُستخدم خط النظام.

## قيود معروفة

- لا خادم ولا قاعدة بيانات: لا مخزون حقيقي مشترك، ولا حفظ للطلبات، ولا تتبع.
- المخزون المعروض بيانات محلية فقط ولا ينقص عند الطلب.
- مساحة localStorage نحو ٥ ميجا؛ الصور المخزنة كـ data URL تستهلكها سريعًا (يتوقف الحفظ برسالة خطأ عند الامتلاء). تصاميم العملاء المحفوظة في السلة تستهلك المساحة أيضًا.
- المعاينة ثنائية الأبعاد ولا تعكس الخامة أو الطباعة الفعلية بدقة.

## لماذا لا تتزامن تعديلات الإدارة بين الأجهزة؟

لوحة الإدارة تحفظ في `localStorage` الخاص **بالمتصفح الحالي على الجهاز الحالي**. ما تعدّله لا يراه العملاء، ولا يظهر على هاتفك أو متصفح آخر، ويضيع إن مُسحت بيانات المتصفح. للتعديل الدائم الذي يراه الجميع عدّل `products.js` وارفعه.

> **لوحة الإدارة تجريبية وغير آمنة:** لا كلمة مرور فيها عمدًا (لأن أي كلمة مرور في JavaScript ظاهرة لكل زائر)، وأي شخص يفتح `#admin` يمكنه التعديل **في متصفحه فقط**. لا تعتمد عليها تجاريًا.

## لماذا يلزم خادم حقيقي لمتجر إنتاجي؟

للمصادقة الآمنة للإدارة، وحفظ المنتجات والصور والطلبات مركزيًا، وإدارة مخزون حقيقي، وبوابة دفع آمنة، ورفع صور العملاء وتخزينها وربطها بالطلب تلقائيًا، وحماية البيانات والنسخ الاحتياطي. استبدل لوحة الإدارة بنظام يعتمد على خادم قبل أي استخدام تجاري حقيقي.
